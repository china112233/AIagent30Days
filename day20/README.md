# Day 20: 框架对比与选型

## 概述

经过前面几天的学习，我们已经深入了解了 LangChain、LangGraph、LlamaIndex、Semantic Kernel、Dify 和 AutoGen 等主流 LLM 开发框架。本天将对这些框架进行全面对比分析，帮助你在实际项目中做出正确的技术选型决策。

## 学习目标

- 全面了解各框架的核心定位和设计理念
- 掌握各框架的功能特性和性能差异
- 理解不同场景下的框架适用性
- 学会根据项目需求进行技术选型
- 了解框架组合使用的最佳实践

### 2. 六大框架核心定位

| 框架 | 出品方 | 核心定位 | 设计理念 | 主要场景 |
|------|--------|----------|----------|----------|
| **LangChain** | LangChain AI | 通用链式编排 | 模块化、可组合 | 通用 LLM 应用 |
| **LangGraph** | LangChain AI | 有状态图编排 | 循环、分支、持久化 | 复杂 Agent 工作流 |
| **LlamaIndex** | LlamaIndex | 数据连接与检索 | 数据优先 | RAG、知识库应用 |
| **Semantic Kernel** | Microsoft | 语义技能编排 | 技能驱动、规划 | 企业应用集成 |
| **Dify** | LangGenius | 低代码平台 | 可视化、开箱即用 | 快速原型、无代码 |
| **AutoGen** | Microsoft | 多 Agent 对话 | Agent 自主协作 | 多 Agent 研究 |

### 9. 场景选型推荐

| **复杂工作流** | LangGraph | - | 循环分支状态管理 |

| **快速原型验证** | Dify | LangChain | Dify 可视化零门槛 |
| **生产级部署** | LangChain + LangGraph | Dify(云) | 组合使用各取所长 |
| **研究实验** | AutoGen | LangGraph | 学术探索灵活度高 |
