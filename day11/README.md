#### 2.3 BM25 算法详解

```python
"""
BM25 (Best Matching 25) 是关键词检索的经典算法

BM25 评分公式：
Score(Q, D) = Σ IDF(qi) * (f(qi, D) * (k1 + 1)) / (f(qi, D) + k1 * (1 - b + b * |D|/avgdl))

其中：
- qi: 查询中的第 i 个词
- f(qi, D): 词 qi 在文档 D 中的词频
- |D|: 文档 D 的长度
- avgdl: 平均文档长度
- k1: 词频饱和参数（通常 1.2-2.0）
- b: 文档长度归一化参数（通常 0.75）
- IDF(qi): 逆文档频率 = log((N - n(qi) + 0.5) / (n(qi) + 0.5))
  - N: 文档总数
  - n(qi): 包含词 qi 的文档数

优点：
1. 考虑了词频（TF）和逆文档频率（IDF）
2. 对长文档有惩罚（避免长文档优势）
3. 词频饱和效应（避免高频词过度影响）
4. 可调参数适应不同场景
"""

# BM25 参数调优
bm25_params = {
    "k1": 1.5,      # 词频饱和参数
                   # 较小值：词频更重要
                   # 较大值：词频饱和更慢
    
    "b": 0.75,      # 文档长度归一化
                   # 0: 不考虑文档长度
                   # 1: 完全归一化
                   # 0.75: 默认值，适合大多数场景
}
```

#### 3.2 Bi-Encoder vs Cross-Encoder

```
┌─────────────────────────────────────────────────────────────┐
│               Bi-Encoder vs Cross-Encoder                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Bi-Encoder (用于粗检索)                                    │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                                                     │   │
│  │   Query ──┐                                        │   │
│  │           ├──→ Encoder ──→ Query Vector          │   │
│  │           │                                        │   │
│  │   Doc ────┘                                        │   │
│  │           ├──→ Encoder ──→ Doc Vector             │   │
│  │                                                     │   │
│  │   Similarity = cosine(Query Vector, Doc Vector)   │   │
│  │                                                     │   │
│  │   特点：                                            │   │
│  │   ✅ 文档可预计算向量                              │   │
│  │   ✅ 检索速度快（向量索引）                        │   │
│  │   ❌ Query 和 Doc 独立编码，交互信息有限           │   │
│  │                                                     │   │
│  │   适用：大规模初检（百万级文档）                   │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  Cross-Encoder (用于重排序)                                 │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                                                     │   │
│  │   [CLS] Query [SEP] Document [SEP]                 │   │
│  │            │                                       │   │
│  │            ▼                                       │   │
│  │         Encoder                                    │   │
│  │            │                                       │   │
│  │            ▼                                       │   │
│  │       Relevance Score                              │   │
│  │                                                     │   │
│  │   特点：                                            │   │
│  │   ✅ Query 和 Doc 联合编码，捕获深层交互           │   │
│  │   ✅ 精确度更高                                    │   │
│  │   ❌ 不能预计算，需要实时推理                     │   │
│  │   ❌ 计算成本高（对每个文档对都要推理）           │   │
│  │                                                     │   │
│  │   适用：小规模精排（Top-100 以内）                 │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  最佳实践：两阶段检索                                       │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  1. Bi-Encoder 快速检索 Top-100                    │   │
│  │  2. Cross-Encoder 精确重排 Top-100 → Top-5        │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 3.3 重排序模型选择

| 模型 | 类型 | 语言 | 特点 |
|------|------|------|------|
| **bge-reranker-large** | Cross-Encoder | 多语言 | 中文效果好，推荐 |
| **bge-reranker-base** | Cross-Encoder | 多语言 | 平衡性能和速度 |
| **cohere-rerank** | API | 多语言 | 托管服务，效果好 |
| **ms-marco-MiniLM** | Cross-Encoder | 英文 | 英文效果好，轻量 |
| **monologg/bert-base** | Cross-Encoder | 英文 | 经典英文重排模型 |
| **cross-encoder/m-NLI** | Cross-Encoder | 英文 | 通用英文模型 |

```
选择建议：

中文场景 ──→ BGE Reranker (bge-reranker-large)
英文场景 ──→ MS MARCO MiniLM 或 Cohere Rerank
多语言 ──→ BGE Reranker 或 Cohere Rerank
追求速度 ──→ 选择较小的模型 (base/small)
追求精度 ──→ 选择较大的模型 (large)
无需部署 ──→ Cohere Rerank API
```

### 5. RAG 评估

#### 5.1 评估框架

```
┌─────────────────────────────────────────────────────────────┐
│                      RAG 评估框架                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                    RAGAS 框架                         │   │
│  │           (RAG Assessment)                          │   │
│  ├─────────────────────────────────────────────────────┤   │
│  │                                                      │   │
│  │  检索评估:                                           │   │
│  │  ┌─────────────────────────────────────────────┐   │   │
│  │  │  Context Precision (上下文精确率)            │   │   │
│  │  │  检索到的上下文中相关内容的比例             │   │   │
│  │  │                                              │   │   │
│  │  │  Context Recall (上下文召回率)              │   │   │
│  │  │  所有相关信息被检索到的比例                 │   │   │
│  │  └─────────────────────────────────────────────┘   │   │
│  │                                                      │   │
│  │  生成评估:                                           │   │
│  │  ┌─────────────────────────────────────────────┐   │   │
│  │  │  Faithfulness (忠实度)                       │   │   │

│  │  │                                              │   │   │
│  │  │  Answer Relevance (回答相关性)              │   │   │
│  │  │  回答是否恰当地回答了问题                   │   │   │
│  │  │                                              │   │   │
│  │  │  Answer Correctness (回答正确性)            │   │   │

│  └─────────────────────────────────────────────────────┘   │
│                                                             │

│  ```python                                                  │

│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 5.2 评估指标详解

| 指标 | 计算方式 | 理想值 | 说明 |
|------|----------|--------|------|
| **Context Precision** | 相关片段数 / 检索片段数 | > 0.8 | 检索精确度 |
| **Context Recall** | 检索到的相关信息 / 所有关联信息 | > 0.8 | 检索完整度 |
| **Faithfulness** | 基于上下文的陈述 / 总陈述数 | > 0.9 | 生成忠实度 |
| **Answer Relevance** | LLM 评分 | > 0.8 | 回答相关性 |
| **Answer Correctness** | 与标准答案比对 | > 0.9 | 回答正确性 |

## 文件说明

### 1. hybrid_retrieval.py - 混合检索实现

实现向量检索和关键词检索的融合：
- `BM25Retriever`: BM25 关键词检索器
- `VectorRetriever`: 向量检索器
- `HybridRetriever`: 混合检索器（RRF 融合）
- 多种融合策略实现

### 2. reranker.py - 重排序实现

实现重排序模型：
- `Reranker`: 重排序基类
- `CrossEncoderReranker`: Cross-Encoder 重排序
- `LLMReranker`: LLM 重排序
- 多种重排序策略

### 3. knowledge_base_optimizer.py - 知识库优化

实现知识库优化策略：
- `DocumentCleaner`: 文档清洗
- `AdaptiveChunker`: 自适应切分
- `QualityScorer`: 质量评分
- `IncrementalUpdater`: 增量更新

### 4. advanced_rag_engine.py - 进阶 RAG 引擎

## 使用示例

### 1. 混合检索

```python
from hybrid_retrieval import HybridRetriever, BM25Retriever, VectorRetriever

# 创建混合检索器
hybrid = HybridRetriever(

from advanced_rag_engine import AdvancedRAGEngine, AdvancedRAGConfig

### 2. 常见问题排查

| 检索不相关 | 向量模型不适合 | 换嵌入模型 |
| 检索不相关 | 切分不当 | 调整切分参数 |
| 检索不相关 | 查询表达差 | 查询重写/扩展 |
| 回答幻觉 | 检索质量差 | 提高检索精度 |
| 回答幻觉 | 上下文不足 | 增加 top_k |
| 回答幻觉 | 模型问题 | 提示词优化 |
| 响应慢 | 重排序耗时 | 减少候选数量 |
| 响应慢 | 向量库性能 | 优化索引 |
| 成本高 | 嵌入调用多 | 批量处理、缓存 |
